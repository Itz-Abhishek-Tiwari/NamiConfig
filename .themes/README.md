# GTK Themes

This directory contains the GTK themes used in the dotfiles setup.

## Themes

- `gruvBox-dark`: Dark theme variant based on the Gruvbox color palette.
- `gruvBox-light`: Light theme variant based on the Gruvbox color palette.

## Integration

These themes are applied via GTK configuration settings (managed by system tools or manually in `.config/gtk-3.0/settings.ini` and `.config/gtk-4.0/settings.ini`).
