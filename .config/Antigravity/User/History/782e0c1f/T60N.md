# NamiConfig Transformation Walkthrough

Your dotfiles are now cleaner, more modular, and professionally organized.

## 🏁 Final Results

### 1. Robust Dotfiles Management
- **Flattened Repo**: All configuration files are now in the root of `~/NamiConfig`, making the structure transparent.
- **`setup.sh`**: A battle-tested bootstrap script that uses `GNU Stow`. It automatically:
    - Detects and backs up conflicting files in your home directory.
    - Handles broken symlinks from previous setups.
    - Ensures a clean stowing process for your local user.

### 2. Dynamic Theme System
- **Generalized Toggling**: `mode_toggle.py` now dynamically resolves theme families. Adding a new theme to `~/.config/NamiThemes/` will automatically integrate it into the system.
- **Rofi Menu**: The theme selection menu (`SUPER+B`) is now fully dynamic and auto-populates from your themes folder.

### 3. Hyprland Optimizations
- **Error Logging**: Real-time logs are captured to `~/.config/hypr/hyprland.log` and can be viewed instantly with `SUPER+SHIFT+L`.
- **Modern Syntax**: Refactored window rules and environment variables for better performance and compatibility with Hyprland v0.40+.
- **NVIDIA Performance**: Consolidated environment variables to ensure the smoothest Wayland experience.

## 🛠 Usage Tips

- **Add a Theme**: Just drop a new folder into `~/.config/NamiThemes/` and it will show up in the `SUPER+B` menu.
- **Re-Stow**: If you add new files to `NamiConfig`, just run `./setup.sh` again to symlink them.
- **Debug**: If something feels off, hit `SUPER+SHIFT+L` to see the live logs.

Your system is now a highly modular and maintainable "rice". Enjoy the new setup!
