# Zsh Configuration

Modular Zsh setup for a clean and efficient shell experience.

## Structure

- `core.zsh`: Core shell settings and options.
- `env.zsh`: Environment variables.
- `aliases.zsh`: Custom shell aliases.
- `functions.zsh`: Custom shell functions (e.g., `gitwho`).
- `plugins.zsh`: Plugin management and loading.
- `theme.zsh`: Prompt and prompt styling.
- `completion.zsh`: Zsh completion settings.
- `fzf.zsh`: FZF integration.

## Key Features

- **Categorized Configs**: Easy to manage and maintain.
- **Custom Functions**: Productive helpers for Git and system management.
- **Performance Focused**: Minimal overhead for fast shell startup.
