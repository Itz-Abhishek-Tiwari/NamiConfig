# User Configurations

This directory contains configuration files for various applications and system components.

## Subdirectories

- [hypr/](hypr/README.md): Hyprland window manager.
- [waybar/](waybar/README.md): Status bar.
- [fuzzel/](fuzzel/README.md): Application launcher.
- [swaync/](swaync/README.md): Notification center.
- [ghostty/](ghostty/README.md): Primary terminal emulator.
- [kitty/](kitty/README.md): Alternative terminal emulator.
- [zsh/](zsh/README.md): Shell extra scripts and aliases.
- `themes/`: Theme files (Gruvbox palette).
- `wallpapers/`: Wallpaper assets.
- `fastfetch/`: System information tool.
- `gtk-3.0/` / `gtk-4.0/`: GTK specific settings.
