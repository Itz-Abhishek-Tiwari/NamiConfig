# Fuzzel Configuration

[Fuzzel](https://codeberg.org/dnkl/fuzzel) is a Wayland-native application launcher, similar to rofi/dmenu.

## Configuration

- `fuzzel.ini`: Main configuration file.

## Features

- **Fast**: Wayland-native and very responsive.
- **Customizable**: Colors, fonts, and layout can be easily tweaked.
- **Dmenu mode**: Used for scripts like the clipboard manager and power menu.
