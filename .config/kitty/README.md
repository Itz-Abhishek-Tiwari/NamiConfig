# Kitty Configuration

[Kitty](https://sw.kovidgoyal.net/kitty/) is a GPU-based terminal emulator.

## Configuration

- `kitty.conf`: Main configuration file.
- `theme.conf`: Theme-specific colors (sourced by `kitty.conf`).

## Usage

While [Ghostty](https://ghostty.org/) is the primary terminal in this setup, Kitty is included as a robust alternative or fallback.
