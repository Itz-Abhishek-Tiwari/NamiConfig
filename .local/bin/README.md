# Scripts

This directory contains custom scripts for system management and productivity.

## Scripts Overview

- `theme-switch`: Toggle between Dark and Light Gruvbox themes.
- `wallpaper-cycle`: Rotate through wallpapers for the current theme.
- `screenshot`: Utility for full, region, or window screenshots.
- `volume`: Control system volume and microphone.
- `brightness`: Control screen brightness.
- `fuzzel-calc`: App launcher-integrated calculator.
- `power-menu`: System power management (reboot, shutdown, etc.).
- `git-sync`: Sync dotfiles with the Git repository.
- `optimize-dev.sh`: Helper for developer environment optimization.

## Usage

These scripts are designed to be triggered via Hyprland key bindings (see [.config/hypr/README.md](../.config/hypr/README.md)).
